A secret research lab called “Helix Quantum Systems” built a prototype authentication system for securing classified experiments.

One night, the system was found running in “emergency mode” with all source code deleted.
Only a single binary and an encrypted file remain.

The lab notes say:

“If anyone is able to bypass this vault, the system was never truly secure.”

Your mission is to break into the vault and recover what is hidden inside.
